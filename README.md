# NivPay

A streaming stablecoin subscription protocol targeting Monad.

## Current state

There is no product code in this repository yet. What exists is a benchmark
harness built to answer one architectural question before anything gets
written on top of it:

> Is eager per batch settlement economically viable on Monad, or is lazy
> accrual forced?

The measured answer, the cost model and the verdict are in
[BENCHMARK.md](./BENCHMARK.md).

## Layout

    src/MockStable.sol      minimal 6 decimal ERC-20, test only
    src/StreamBench.sol     three settlement variants over one stream model
    test/StreamBench.t.sol   gas sweep plus correctness tests
    script/cost_model.py    turns measured gas into USD cost per stream
    bench/gas.json          raw measurement output, regenerated by the sweep

## Running it

Requires Foundry and Python 3. No paid RPC, no API keys, no third party
dependencies beyond forge-std.

    forge test -vv
    python script/cost_model.py --fan-in 100

The cost model queries `eth_gasPrice` from the Monad mainnet RPC at
`https://rpc.monad.xyz` (chain id 143) and takes MON/USD as an argument.
Neither is hardcoded into the arithmetic, and both are printed at the top of
the output. To run without network access:

    python script/cost_model.py --gas-price-gwei 100 --mon-usd 0.0268

## Scope

Nothing here is deployed and nothing here is production code. The contracts
have no access control, no solvency checks and no stream lifecycle beyond an
active flag, because adding those would cost the same in all three variants
and would not change the comparison.
